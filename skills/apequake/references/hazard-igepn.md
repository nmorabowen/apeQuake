# IG-EPN hazard and NEC hazard curves

## IG-EPN probabilistic hazard (`apeQuake.hazard`, apeQuake#7, #9)

Snapshot of the IG-EPN "Mapa Digital Interactivo del Peligro Sísmico Probabilístico para el
Ecuador" (ArcGIS feature services), regenerated by `scripts/igepn/fetch_igepn.py` (stdlib).
3146 cells (0.08° lattice, some merged), rock Vs30 = 760, periods
`PERIODS = (0, .05, .07, .1, .2, .5, 1, 2)`, `RETURN_PERIODS = (475, 2475)`,
`STATS = ("mean", "q16", "q50", "q84")`.

```python
from apeQuake.hazard import EcuadorHazard
hz = EcuadorHazard()
s = hz.site(-0.22, -78.51, interp="bilinear")    # or hz.site("Quito"); interp "cell" (default)
s.published(2475, "mean")      # ndarray over PERIODS (index 4 = 0.2 s, 6 = 1.0 s)
s.uhs(tr=975, method="auto")   # DataFrame[T, Sa, source]; other TR via power law or digitized curves
s.hazard_curve(period=0.2)     # DataFrame[sa_g, rate, tr, source]
s.cell_id, s.distance_km
hz.uhs_at(["Quito", (-2.19, -79.89)], tr=475)
hz.hazard_map(tr=475, period=0.2)   # cell_id, lat, lon, sa
hz.plot_map(...); hz.explore("map.html")   # standalone Leaflet HTML (~3 MB)
```

- `site()` uses point-in-polygon on the real cell outlines (merged cells); `"bilinear"` falls back
  to the cell value when a neighbour is missing. Points outside: nearest cell + warning
  (`strict=True` raises).
- Also: `capitals()`, `population()`, `catalog("shallow"|"deep"|"historical")`, `admin(level)`,
  `sources(...)`, `faults()`, `find(name)`, `citation()`; `fetch_recent_events()` (live).

## NEC digitized hazard curves (`apeQuake.nec`, apeQuake#6)

NEC-SE-DS §3.1.2 / appendix 10.3 curves for 23 provincial capitals: PGA and Sa(0.1, 0.2, 0.5,
1.0 s), rock.

```python
from apeQuake.nec import load_hazard_database, NEC_RETURN_PERIODS   # 72, 225, 475, 2500
db = load_hazard_database()
c = db.nearest(lat, lon)            # or db["Quito"]
T, sa = c.uhs(475)                  # tuple of arrays
c.hazard_table()
c[0.2].a_at_return_period(2500); c[0.2].rate_at(1.0); c[0.2].extrapolate(...)
```

The NEC curves at 475 yr reproduce the NEC rock spectrum (Quito Sa(0.2) 0.979 vs η·Z 0.992);
IG-EPN 2025 is ~40 % above NEC at 0.2 s on rock, similar at 1.0 s.
